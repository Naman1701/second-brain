# Physical Uplink Shared CHannel - PUSCH

PUSCH carries uplink user data. Two specifications divide the work between them. 38.212 defines the bit level steps, from the transport block down to the coded stream, and 38.211 defines everything after that, from scrambling out to the resource grid.
