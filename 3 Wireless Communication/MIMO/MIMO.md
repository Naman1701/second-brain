# MIMO

MIMO uses multiple antennas at the transmitter and/or receiver to improve spectral efficiency and reliability.

## Key concepts
- spatial multiplexing
- diversity gain
- array gain
- channel matrix
- precoding and combining

## Why it matters
MIMO is central to modern wireless systems, especially in 5G.
