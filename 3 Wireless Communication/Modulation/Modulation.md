# Modulation

Modulation maps digital information onto a waveform suitable for transmission through a physical channel.

## Common schemes
- QPSK
- QAM
- PSK
- PAM

## Key performance tradeoffs
- spectral efficiency
- robustness to noise
- implementation complexity

## In wireless systems
Modulation choice is linked to:
- SNR
- channel quality
- coding rate
- link adaptation
